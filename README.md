# Student Success Analyzer

Interactive R Shiny application for exploring how study habits affect academic performance through statistical modeling and visualization.

## Live Application

https://aronibors.shinyapps.io/Student_Performance_Analyzer/

## Features

- Predicts test and homework performance
- Interactive decision-boundary visualization
- Monte Carlo simulation
- PCA biplot
- Multiple regression analysis
- MANOVA
- Correlation analysis

## Technologies

- R
- Shiny
- ggplot2
- dplyr

## Repository

This repository contains the source code for the deployed Shiny application.
